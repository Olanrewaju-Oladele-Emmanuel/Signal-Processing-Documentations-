Day 05 - Phase Shift

Today I learned about phase shift in signals.

Same frequency, different starting point. Used sin(t + phi) to show 0 deg, 90 deg, 180 deg phase.

0 degree = normal sine
90 degrees = cosine
180 degrees = inverted sine

I also tested Euler formula to understand complex phase.
