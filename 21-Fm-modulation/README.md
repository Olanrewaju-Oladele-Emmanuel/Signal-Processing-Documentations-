Day 21: FM Modulation

Day 21 done.

So today I did Frequency Modulation. Yesterday was Amplitude Modulation where the height was changing. For FM, frequency  change. The height stays same but the wave will tighten and loosen.

What I used:
message 5hz
carrier 50hz
kf 20

I also tried kf 5 and 50 to see difference. 50 makes it more obvious.

Files in this folder:
day21_fm_modulation.py = code for pydroid 3
day21_fm_modulation.png = my plot



Major thing I noticed is that when the message is at the top, the FM wave packs together. When message is down, it spreads. And the last plot shows frequency moving from 30 to 70.
